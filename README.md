# 🍳 厨房计时器

一个基于 React + Vite 的多任务厨房计时器网页应用。

## 功能

- 8 个常用食材预设（米饭、面条、水煮蛋等），一键添加
- 支持多个计时器并行运行
- 自定义菜名与分钟数（支持 0.5 分钟粒度）
- 开始 / 暂停 / 重置 / 删除
- 到点响铃提醒（Web Audio API）+ 红色闪烁 + 手机震动
- 进度条与剩余时间大字体显示
- 响应式布局，适配手机与桌面

## 快速开始

```bash
npm install
npm run dev
```

然后打开终端中提示的地址（默认 http://localhost:5173）。

## 构建与预览

```bash
npm run build   # 产出 dist/ 目录
npm run preview # 本地预览构建结果
```
